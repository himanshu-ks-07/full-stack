# Lab Sheet 7 - Database Solutions

This folder contains the complete solutions for **Lab Sheet 7** (college_db).

- **`LabSheet7_Solution.sql`**: Full MySQL / PostgreSQL / MariaDB script with DDL, DML, Joins, Subqueries, Indexes, Views, Transactions, and Window Functions.
- **`run_lab7.py`**: Zero-setup runner script (runs directly without any password or server).

## How to Run:
- **Python (Zero Setup / Instant):**
  ```bash
  python run_lab7.py
  ```
- **MySQL Command Line:**
  ```bash
  mysql -u root -p < LabSheet7_Solution.sql
  ```
